Finished items move here automatically once they're older than the archive window. Nothing is deleted — everything below is still searchable and can be reopened.

Settings

Archiving only hides a card from the board. It stays searchable and can be reopened at any time. Deleting is always manual.
When Ongoing is full, the lane refuses a new item until you finish one or move it to Waiting.

Your board lives in a private GitHub Gist. Paste a token with the gist scope only — it stays in this browser and is sent only to api.github.com.

Create a token on GitHub → Tick gist, generate, copy it here. Tokens expire — when sync stops, make a new one and paste it in.

Keep the same ID on every device so they share one board.

How it works

Everything lands in Inbox. You decide once whether it's This Week or Later. It becomes Ongoing only when you actually start, Waiting when the ball's in someone else's court, then Done.

Items carried over in This Week wear a 2nd week badge so stale work is visible rather than quietly blending in.
